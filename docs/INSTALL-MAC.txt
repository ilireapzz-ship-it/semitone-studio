SEMITONE STUDIO for macOS — install and use in FL Studio
========================================================

INSTALL
1. Copy "Semitone Studio.vst3" to  ~/Library/Audio/Plug-Ins/VST3/
   Copy "Semitone Studio.component" to  ~/Library/Audio/Plug-Ins/Components/
   Put "Semitone Studio.app" in Applications.
2. These test builds are not notarised yet. If FL says "This plugin failed to load", open
   System Settings > Privacy & Security, scroll to Security and click "Open Anyway" next to
   "Semitone Studio.vst3", then quit and reopen FL Studio. (Or run in Terminal:
   xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Semitone Studio.vst3" ~/Library/Audio/Plug-Ins/Components/"Semitone Studio.component")
3. FL Studio: Options > Manage plugins > Find installed plugins. Use the VST3 version in FL.

PLAY YOUR INSTRUMENTS FROM EACH PART
Each part leaves on its own MIDI channel: Melody 1, Chords 2, Bass 3, Drums 10.
1. Add Semitone Studio to the Channel Rack. It makes no sound itself.
2. In its window click the gear (wrapper settings) > MIDI > Output port = 1.
3. Add instruments (Omnisphere, Kontakt...). In each one's gear > MIDI set Input port = 1.
   Instruments with a MIDI-channel setting (Omnisphere parts are Ch 1-8) pick their part by channel.
4. Use FL's SONG mode and press Play. (In PAT mode FL loops the pattern length.)

DRAG PARTS INTO FL STUDIO
Drag a part chip (Melody, Chords, Bass, Drums, All parts) from "Into your DAW" onto FL's
Channel Rack. FL shows its Import MIDI box: press Accept.

YOUR MIDI KEYBOARD
Select the Semitone Studio channel and play: notes reach Play along, Ear training and live play.

The song is saved inside your FL project. Exports open a normal Save dialog
(default folder: Documents/Semitone Studio/Exports).
